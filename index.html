THE BASICS

How Hi-Lo counting works

It’s a way to keep track of which cards have left the shoe—not a way to predict the exact next card.

01

Give each card a value

2–6 +1 7–9 0 10–A −1
02

Keep a running count

Start at zero. Add each card’s value as it becomes visible. Low cards raise the count; high cards lower it.

03

Adjust for the decks left

Divide the running count by the estimated decks remaining to get the true count. It helps compare counts at different shoe depths.

ⓘ This is a practice tool for learning the arithmetic. A win returns twice your bet; a push returns your bet. Card counting does not guarantee a win.
